# 업무 지표 자동 집계 자동화 — 첫 작은 완성

주별 자유 입력에서 출금 대상·성공 건수를 추출하여 월 실적과 기존 대시보드에 연결하는 Google Sheets 수식 기반 구현입니다.

공개 내용은 [업무지표-자동화/public](업무지표-자동화/public)에 있습니다. 이 저장소에는 실제 업무 데이터, 운영 시트·시험 시트의 링크나 ID, 개인정보, 원본 자료, 비밀값이 없습니다.

현재 결과물은 native Google Sheets 수식과 구현 요청의 기록입니다. Apps Script나 별도 실행 서비스를 배포한 프로젝트가 아닙니다. 제공한 설정만으로 기존 내부 workbook이 생성되지는 않습니다.

가상 샘플과 검증 요약, 한계는 공개 폴더의 README.md와 docs/verification.md를 확인하세요.
