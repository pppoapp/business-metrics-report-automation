# 가상 샘플로 확인하기

실제 시험 위치는 별도 Google Sheets 시험용 사본의 입력_후원자예우 탭이었습니다. 문서 주소와 ID는 공개하지 않습니다.

1. 입력_후원자예우 B6에서 테스트_후원자예우를 선택합니다.
2. B9에 `이번 주 출금 대상 100건, 성공 97건`을 입력하고 Enter로 확정합니다.
3. 카드에 대상 100·성공 97·성공률 97.0%, 월지표 연결 상태가 표시됩니다.
4. B9를 `이번 주 출금 대상 200건, 성공 190건`으로 변경하면 95.0%가 됩니다.
5. 실시간 확인 B14:B16과 연결한 지표 셀에서 월 대상·성공·비율을 확인합니다.

나머지 주의 내용 셀: B26, B43, B60, B77. 같은 주 수정은 값을 대체합니다.
월 시험 시작값은 0이며 이미 카드에 포함한 값을 기존 집계값으로 다시 넣지 않습니다.

JSON은 수식·구현 요청 기록이며 독립 실행 프로그램이 아닙니다. 연결 대상 2026년 지표·2026 성과 대시보드는 이 저장소에 없으므로 자체 시험 환경의 대상 셀 계약을 먼저 준비해야 합니다.
