# 주별 입력 → 월 실적 → 대시보드

## 현재 구현

- 회계·광고·후원자예우·물품기부의 입력 카드와 현재 기록표.
- 후원자예우 입력의 출금 대상·성공 건수 추출과 월 집계 연결.
- 같은 주 카드 수정 시 이전 값을 대체하고 중복 가산하지 않음.
- 성공 건수가 대상보다 많거나 수치가 불명확하면 반영 보류.
- 월요일~일요일 기준, 월 경계에서 구간을 분리한 2026년 10월 카드 5개.

Google Sheets에서 실제 구현·확인했으며 결과물 내부 AI 호출과 개발용 하위 에이전트는 실행하지 않았습니다. 이번 공개는 저장만 수행하며 서비스 배포를 포함하지 않습니다.

## 파일

- src/SheetImplementation.json: 실제 사용한 입력 탭 생성 요청·수식·연결 계약에서 내부 문서 식별자를 제거한 사본.
- samples/withdrawal-example.csv: 가상 대상 100건·성공 97건 샘플.
- docs/usage.md: 실행 위치·수정 예시·예상 결과.
- docs/verification.md, proofs/verification.json: 실제 시험의 가상 입력 결과만 발췌.
- PLAN.md, TEAM.md, DESIGN.md: 현재 범위·책임·공개용 디자인 적용 요약.

## 한계

기존 실적·대시보드와 내부 목표표는 제공하지 않습니다. JSON의 연결 수식은 대상 탭과 셀이 준비된 경우에만 적용할 수 있습니다. 자체 데이터를 사용할 때는 별도 테스트 workbook에서 매핑을 확인해야 합니다.

다른 업무는 현재 기록만 제공하며 KPI 매핑·광고 API·AI 피드백·콘텐츠 제작·메일·정기 실행은 아직 구현하지 않았습니다. 한 업무·한 주에 카드 하나이므로 동시 입력 충돌 방지는 미구현입니다. 아래 표는 현재 상태이고 수정 전 원문을 누적 저장하는 감사 로그가 아닙니다.

원래 workbook 복사본의 일부 전년도 외부 참조는 별도 연결 승인이 필요했습니다. 해당 자료·참조 주소는 공개하지 않습니다. 참가자가 직접 실행한 결과는 아직 확인하지 않았습니다.
