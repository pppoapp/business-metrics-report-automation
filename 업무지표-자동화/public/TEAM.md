# 역할과 책임

총괄이 Google Drive/Sheets 연결 도구로 시험용 사본 구현·검증을 순서대로 수행했습니다. 별도 구현 작업자는 실행하지 않았으며 모델 지정값이 실행됐다고 주장하지 않습니다.

| 역할 | 담당 자료 | 완료 조건 |
| --- | --- | --- |
| 총괄·통합·검증 | src/SheetImplementation.json, PLAN.md, docs/, proofs/ | 승인된 지표 연결·검증 기록과 공개 데이터 검사 |
| 참가자 | 가상 예시로 직접 사용 | 입력 수정에 따른 결과 확인, 다음 범위 선택 |

의존 관계: 샘플·기간·입력 배치 선택 → 복사본 생성 승인 → 카드·수식 → 월 지표 연결 → 실제 계산값 확인 → 참가자 직접 확인.

현재 등록 단계에서는 총괄이 저장·업로드만 수행합니다. 하위 에이전트의 추가 위임을 금지합니다.
